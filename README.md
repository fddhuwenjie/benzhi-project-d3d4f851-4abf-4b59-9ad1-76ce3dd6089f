# wayfinding-release-gate

`wayfinding-release-gate` 是面向公共建筑导向标识设计团队的放样审批工作台。系统把勘测基线冻结、路径与候选标识维护、确定性规则校验、问题整改、独立走查、签署批准和不可变安装包冻结组织为一条可追溯流程。

现有工作台在不可逆操作前提供确定性预检：基线预检定位节点、连接和身份清单阻断项；候选标识预检展示规范化后的新增、修改与删除差异。规则问题附带受影响入口、目的地和路径，可组合筛选；每次整改追加证据版本，相关标识变化会使旧证据进入待重新确认状态。走查失败后只生成系统指定的失败站点复验清单，批准冻结前还会校验源修订和候选摘要。

服务由 Go 直接提供原生单页工作台和同源 JSON 接口，不需要 Node 构建链。业务数据保存在本地文件中，包含原子项目快照、持久幂等记录、摘要相连的事件帧和按 SHA-256 摘要命名的安装包。

## 构建

需要 Go 1.22 或更高版本。

```bash
go build ./cmd/wayfinding
```

## 运行

默认只监听高位回环地址 `127.0.0.1:19081`，数据写入 `./data`：

```bash
go run ./cmd/wayfinding
```

可显式指定回环监听地址和数据目录：

```bash
go run ./cmd/wayfinding -addr=127.0.0.1:19181 -data=./data
```

未提供 `-addr` 时，也可以通过 `PORT` 指定端口，服务将绑定 `127.0.0.1:<PORT>`。服务拒绝省略主机、非回环地址和低于 `1024` 的端口。浏览器访问监听地址即可进入工作台。

## 测试

运行全部回归测试：

```bash
go test ./...
```

运行真实 HTTP 完整流程自检。自检使用临时数据目录，完成建项、基线冻结、标识编辑、规则校验、走查、签署、安装包冻结与深度核验后主动退出：

```bash
go run ./cmd/wayfinding -selftest -addr=127.0.0.1:19081
```

## 数据与并发语义

所有写请求都必须携带 `request_id`、`expected_revision` 和 `actor_id`。同一项目的命令串行处理，不同项目可并行；陈旧 revision 返回 `revision_conflict`，同一 `request_id` 改变请求内容返回 `idempotency_conflict`。只读预检、问题筛选和冻结包深度核验不会增加项目修订或时间线事件。项目冻结后只允许读取时间线、下载安装包和重新核验摘要、结构、业务终态与事件链。
